# Arena NLD 24hs

Sitio web de Arena NLD 24hs — gimnasio 24 horas, 365 días en Ciudad Jardín, Buenos Aires. Apertura octubre 2026.

Entrenamiento · Salud · Comunidad

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- shadcn/ui (Radix UI)

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Configuración

Los datos editables del sitio (WhatsApp, redes, fecha de apertura, nav) están en [lib/site-config.ts](lib/site-config.ts). Clases, planes y testimonios están en [data/](data).
